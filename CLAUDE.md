## UI work

- For any UI design, build, review or fix (web especially), invoke the `ui-ux-pro-max` skill first and run its Pre-Delivery Checklist before finishing.
- Keep the app's own brand: colours from `lib/app-theme.ts`, text styles from `lib/ui.ts`, spacing from `lib/spacing.ts`, icons from `components/icon.tsx`. Ignore the skill's generic palette and font suggestions.
- Check web changes at 375, 768 and 1440 px widths, in light and dark.
